# D. First-principles teaching progression

Rule: **no term appears before the viewer has seen the thing it names.** Each step only uses ideas from the steps above it.

1. **A rule on letters** (substitution) — see two alphabets and arrows. *Word introduced: none yet.*
2. **A fixed rule leaks** — same in, same out; frequencies survive.
3. **Move the rule** — a wheel of wires; turning it changes every arrow. *Word: rotor.*
4. **The physical machine** — keyboard, lamps, and the fact that pressing a key closes an electric circuit.
5. **One rotor, physically** — 26 contacts each side, 26 wires; turning it = a new wiring. *Word: permutation* (only now).
6. **Chain of rotors** — composition: out of one wheel into the next.
7. **Reflector** — send current back; consequence 1: same setting decrypts; consequence 2: no letter maps to itself (plant it now; it pays off in the crib).
8. **Stepping** — pawls and notches cause the motion; double step as a mechanical consequence, not a rule to memorise. *Word: state.*
9. **Plugboard** — swap pairs before and after.
10. **Counting** — multiply independent choices; each factor is a part the viewer already knows.
11. **Operating procedure** — daily key + message key; the doubled message key is the leak.
12. **Algebra of the machine** (Rejewski) — cycles in the doubled indicators; only after 5–9, so "permutation" is concrete.
13. **Crib** — guessing plaintext; the "no self-encipherment" planted in 7 eliminates positions.
14. **Menu graph & loops** — pairs from the crib as edges; loops as consistency tests.
15. **Elimination machine** (Bombe) — test all rotor positions, reject contradictions; plugboard handled by the contradiction trick.
16. **Diagonal board** — reciprocity (from 9) wired in as more constraints → fewer false stops.
17. **Human check** — a stop is a hypothesis; verify on a real Enigma.

Every abstraction step (Manim) is bracketed by a physical step (Blender) before and after: *physical → abstract → back to the machine*.
